# Build log 2026

Short weekly notes on what I built and why. Newest first.

## Week of 20 November 2026

I went back to a React chat app I first built in 2023 and made it something I'm happy to show. It now sends the whole conversation with each request, so follow-up questions work, and it has 15 tests and CI on two Node versions. The main decision was to put the guardrails on the server: only user and assistant roles are accepted, so a browser can't slip in its own system prompt, and message count and length are capped before any API call, which keeps costs bounded. Raw API errors never reach the browser. I also added a skills map to my product casebook so a reader can jump to the case that fits the role. On a personal planning app, I added goal checklists, weekly review questions and clash warnings, storing new data under new keys so existing saved data keeps working.

## Week of 17 November 2026

This week I tidied up and extended two of my AI side projects. My Telegram agent for Claude now has an optional daily token budget for each chat, tracked in SQLite, so one busy chat can't run up the API bill for everyone else. My WordPress MCP server got list_comments and get_comment tools to help with moderation. The decision there: approved comments stay public, but held, spam and trashed comments are refused unless credentials are set, and author emails and IP addresses are never requested, so an agent can't leak commenter data by accident. I also added MIT licences across my public repos and filled the gaps in my product casebook.
